# Bases de Meta Ads

Presentación web animada con la base de conocimiento compartida de Meta Ads (estructura, objetivos, Pixel/CAPI, audiencias, presupuestos, ABO/CBO, Advantage+, métricas y estrategias).

## Ver en local

```bash
npx -y http-server -p 5500 -c-1
```

Abrir http://127.0.0.1:5500

- `← →` / espacio para navegar, `f` pantalla completa
- `#n` salta a la slide n (ej. `/#19`)
- `?static` desactiva animaciones (capturas / PDF)

## Archivos

- `index.html` — contenido de las slides
- `styles.css` — diseño y animaciones
- `deck.js` — navegación y escalado
